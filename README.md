# Trek Fit — дневник тренировок

Telegram Mini App / PWA: тренировки, питание, вес, рекорды. Интерфейс на русском, тёмная тема.
Репозиторий: `wwwgolybfs-dev/nerchinskay`.

## Что изменилось в этой версии (переходник)

`index2.html` больше не содержит ни разметки вкладок, ни логики — это **оболочка-переходник**:

* постоянное **меню в левой панели** (на телефоне — выезжающая панель с гамбургером);
* каждая вкладка — **отдельный HTML-файл** в `pages/`;
* оболочка собирает вкладки через `fetch` в контейнер `#view` и только потом запускает `app.js`.

Логика приложения (`app.js`) — прежняя, вынесена из `index2.html` **без изменений**: она ищет
элементы по ID, поэтому все вкладки должны быть в DOM к моменту её запуска. Порядок такой:
`shell.js` → fetch всех `pages/*.html` → `innerHTML` в `#view` → подключение `app.js`.

## Файлы

| Файл | Что делает |
|---|---|
| `index2.html` | Точка входа. Разметка каркаса: `<aside id="app-side">` с меню (`[data-nav]`), топбар с хлебными крошками, `#page-title`/`#page-sub`, контейнер `#view`, экран входа, таймер отдыха, шторка, тост. Спрайт SVG-иконок тоже здесь (общий для всех вкладок). |
| `shell.css` | Новый внешний вид каркаса: сетка `278px + контент`, панель с группами «Дневник / Прогресс / Аккаунт», активный пункт с акцентной полосой, топбар, скелетон загрузки, адаптив (≤980px — выезжающая панель). |
| `shell.js` | 1) открытие/закрытие панели на телефоне; 2) `Promise.all(fetch('pages/*.html'))` → `#view.innerHTML` → подключение `app.js`; 3) deep-link `#/workouts` и `hashchange`; 4) крошки = `#page-title`; 5) `body[data-tab]` для точечных стилей. |
| `app.js` | Вся прежняя логика: Telegram WebApp + haptics, Supabase `api()` с таймаутом и ретраем, каталог упражнений, формулы (e1RM, TDEE, КБЖУ, ИМТ), таймер отдыха, Chart.js, рендеры всех вкладок, формы, вход по коду синхронизации, оффлайн-кэш и очередь, темы, дневник питания, рекорды, программы и режим активной тренировки, уведомления, экспорт CSV, регистрация SW, загрузка данных. |
| `style.css` | Стили содержимого: токены темы, карточки, KPI, списки, формы, кнопки, heatmap, тосты, панель питания, адаптив. Каркас больше не стилизует — этим занимается `shell.css`. |
| `pages/*.html` | Фрагменты вкладок. Каждый — один `<section class="panel" id="panel-<имя>">` без `<html>`/`<head>`. Именно этот ID ищет `app.js` (`showTab` переключает `.panel.active`). |
| `demo.html` | Наполняет `localStorage` демо-данными (профиль, 68 подходов, 12 замеров веса) и открывает `index2.html#/home`. Работает **только на localhost/127.0.0.1** — на боевом домене отключается, чтобы не перезаписать реальные данные. |
| `manifest.json`, `sw.js` | PWA: иконки, `start_url`, офлайн-кэш (сейчас `trekfit-v2`, кэширует оболочку, `pages/*`, `app.js`, `shell.js`, `shell.css`). |
| `vendor/chart.umd.min.js` | Chart.js 4.4.4 (локально, без CDN). |
| `vendor/supabase.js` | supabase-js v2 (UMD). Edge Function — `telegram-api`. |

## Как запустить локально

Открывать двойным щелчком по файлу нельзя: `fetch('pages/*.html')` работает только по http(s).

```powershell
cd F:\project\kachalka\nerchinskay
python -m http.server 8080
# или: npx serve .
```

Затем:

* `http://localhost:8080/demo.html` — демо с тестовыми данными (без Telegram и без кода);
* `http://localhost:8080/index2.html` — обычный запуск (попросит код синхронизации из Telegram).

## Как добавить новую вкладку

1. Создать `pages/<имя>.html` с разметкой `<section class="panel" id="panel-<имя>">…</section>`.
2. Добавить файл в массив `TABS` в `shell.js`.
3. Добавить кнопку в левую панель: `<button class="nav-item" data-nav="<имя>">…</button>`.
4. Добавить `<имя>` в словарь `TITLES` в `app.js` (заголовок и подпись) и ветку в `renderTab()`.
5. Добавить файл в `ASSETS` в `sw.js` и поднять версию кэша.

## Замечания

* `app.js` — тот же код, что был инлайн в старом `index2.html`; при правках вкладок его трогать почти не нужно, вся разметка теперь в `pages/`.
* Меняется `style.css` → поднимай `?v=` в `index2.html` и в `sw.js`.
* В `index2.html` захардкожены URL проекта Supabase и publishable-ключ (секретного ключа в коде нет).
* Дубликаты библиотек и неиспользуемые `motion/anime/591` удалены ранее (коммит `03044af`).
