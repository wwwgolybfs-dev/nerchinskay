# Trek Fit — дневник тренировок

Telegram Mini App / PWA: тренировки, белок и вода, вес, рекорды. Интерфейс на русском, тёмная тема.
Репозиторий: `wwwgolybfs-dev/nerchinskay`.

## Что нового в этой версии

* **Тренировки**: убраны программы и тоннаж. Остались записи, число подходов и кнопка
  «Удалить сегодняшние» (плюс корзина в каждой записи за сегодня) — на случай, если подход
  записан ошибочно.
* **Питание**: убраны калории, углеводы и жиры. Остались белок, спортпит (креатин/протеин)
  и вода. Вода — новый счётчик с целью 30–35 мл/кг и кнопками +200/+250/+500 мл.
* **Расчёты**: убраны карточки «Калории» и «БЖУ». Остались норма белка, спортпит, вода, ИМТ и 1ПМ.
* **Обзор**: вместо калорий — белок за день; график «Объём по неделям» заменён на
  «Подходы по неделям».

Как считается спортпит: креатин — 3 г при весе до 65 кг, 5 г при 65–90 кг, 7 г при весе больше
90 кг; утренняя порция протеина — 0,35 г белка на кг веса (при 79 кг это ≈28 г). Только от веса,
цель и активность не влияют.

## Архитектура

`index2.html` — оболочка-переходник: левое меню, топбар, контейнер `#view`.
Вкладки лежат отдельными файлами в `pages/`, `shell.js` собирает их через `fetch` и только потом
запускает `app.js` со всей логикой.

```
nerchinskay/
├── index2.html      оболочка: панель, топбар, #view, оверлеи
├── shell.css        стили оболочки, адаптив и выезжающее меню
├── shell.js         сборка вкладок, drawer, hash-роутинг, крошки
├── app.js           логика: данные, расчёты, рендеры, удаление, вода, спортпит
├── style.css        стили содержимого вкладок
├── pages/
│   ├── home.html        Обзор
│   ├── workouts.html    Тренировки
│   ├── nutrition.html   Питание (белок, спортпит, вода)
│   ├── weight.html      Вес и состав
│   ├── records.html     Рекорды
│   ├── calc.html        Расчёты
│   └── profile.html     Профиль
├── demo.html        демо-данные для локального просмотра (только localhost)
├── supabase/
│   └── README.md    что добавить в Edge Function для удаления тренировок
├── manifest.json, sw.js, icon*.png/svg
└── vendor/          chart.umd.min.js, supabase.js
```

## Запуск локально

```powershell
cd F:\project\kachalka\nerchinskay
python -m http.server 8080     # или: npx serve .
```

* `http://localhost:8080/demo.html` — демо с тестовыми данными;
* `http://localhost:8080/index2.html` — обычный запуск (попросит код синхронизации).

Открывать файлы двойным щелчком нельзя: вкладки подгружаются через `fetch`.

## Удаление тренировок

Кнопки удаления вызывают действие `delete_workout`:

```json
{ "action": "delete_workout", "payload": { "day": "2026-10-28" } }
{ "action": "delete_workout", "payload": { "ids": ["<uuid>"] } }
```

Если функция отвечает ошибкой, значит в Edge Function ещё нет этой ветки — готовый код
и инструкция лежат в [supabase/README.md](supabase/README.md). Удаление работает только
для сегодняшних записей: история задним числом не редактируется.

## Как добавить вкладку

1. `pages/<имя>.html` с `<section class="panel" id="panel-<имя>">…</section>`.
2. Добавить имя в `TABS` в `shell.js` и кнопку `data-nav` в `index2.html`.
3. Добавить имя в `TITLES` в `app.js` и ветку в `renderTab()`.
4. Добавить файл в `ASSETS` в `sw.js`, поднять версию кэша.

## Замечания

* Меняется `style.css` → поднимай `?v=` в `index2.html` и в `sw.js`.
* В `index2.html` захардкожены URL Supabase и publishable-ключ (секретного в коде нет).
* Дубликаты библиотек и неиспользуемые `motion/anime/591` удалены ранее.
